# 4k_anime · 4K 动漫夸克线路

把一份在线更新的 4K 动漫表格同步为影视仓（TVBox / 影视仓）可直接导入的配置：
分类、封面、年份 / 地区 / 导演 / 演员 / 简介与合集剧集列表均由本项目生成；
解析、登录与取流在 App 内由饭太硬 jar 自带的夸克实现完成，本项目站点只放静态数据。

```
在线表格 ──► GitHub Actions（每周一）──► data/anime.json ──► 静态数据站（Pages）
                                                              │
                            影视仓导入配置 ◄──────────────────┘
                              线路 🎬4K动漫A┃夸克解析
                                目录：本项目 anime.json
                                详情 / 播放：转发给 jar 内饭太硬原生的夸克实现
```

| 项 | 值 |
| --- | --- |
| 数据源 | 在线表格（Luckysheet 结构） |
| 数据站 | <https://huime180.github.io/4k_anime/> |
| 内容规模 | 771 条条目，3 个顶层分类，19 个类别 |
| 运行依赖 | Python 3.9+ 标准库；数据站为纯静态站点，无需服务端 |
| 站点解析 | 无（只有 JSON 与图片） |
| 同步 | GitHub Actions，每周一 04:00 UTC |

## 一、配置地址（导入影视仓）

只维护一份配置 `config/4k_anime_with_fty.json`：饭太硬官方配置，外加插在
「🗂我的云盘┃配置」之后的一条 `4k_anime` 线路。

```
https://gh-proxy.com/https://raw.githubusercontent.com/huime180/4k_anime/main/config/4k_anime_with_fty.json
```
能用的壳子NewBox  https://pan.quark.cn/s/bd846d39e22d
更换 jar 版本后导入时可加 `?t=<时间戳>` 穿透缓存。   
| 项 | 说明 |
| --- | --- |
| 线路 | `key: 4k_anime`，`type: 3`，`api: csp_Anime4KGuard` |
| 目录数据 | `ext.data` 指向数据站的 `anime.json`，`ext.data2` 为 GitHub raw 兜底 |
| 分类 | 全部 / 每周更新 / TV动画合集 / 其余群友资源合集 / 季度档等 20 个 |
| 详情 / 播放 | 转发给 jar 内饭太硬原生的 `Cloud_quark`（经 `Init.loader()` 取得子 DexClassLoader），线路名为其 **夸父原 / 夸父智**，播放地址为 App 本地代理形态 `http://127.0.0.1:<端口>/proxy/play/…` |
| 夸克会话 | 由饭太硬实现持有，在「🗂我的云盘┃配置」扫码登录一次即可 |

## 二、主要特性

* **详情补全**：年份、地区、导演、演员与简介在同步时由 Bangumi 取回并写入数据，App 打开详情页即可显示。
* **合集按二级目录展开**：一季一个分享的合集条目，按其对应目录列取剧集，不列出整季内容。
* **数据静态化**：仓库只保存 `anime.json`、`meta.json` 与封面图片，不保存剧集或文件清单。
* **配置与 jar 自洽**：jar 文件名含内容 md5，配置引用该副本并声明同一 md5，避免缓存组合不一致。
* **自动同步**：每周一次，抓表格、补详情、跟随官方 jar 重建、导出数据与配置。
